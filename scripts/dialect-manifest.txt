# bucket. scripts/dialect-lowering-ratchet.sh FAILS if a dialect def is not listed
# (an UNMARKED toy) and warns on the `review` bucket. Authoritative source for
# lowers/theory: CatCrypt/Crypto/SecureCompilation/VIR/DIALECTS.md.
#
# Format: one `<bucket> <dialectName>` per line.
#   lowers  — has a bytes-reaching lowering (→ Com jasminDialect → x86/ELF, direct
#             or via the DialectLoweringChain). Usable on an emit path.
#   theory  — correspondence / MLIR-mirror / optimizer-playground. NO lowering out,
#             zero emit traffic. MUST NOT be wired into an emit/plan path.
#   test    — smoke / example / pilot dialect, not shipped.
#   review  — not yet classified against DIALECTS.md; tracked (warned), not silently
#             unmarked. Drive this bucket to zero.
