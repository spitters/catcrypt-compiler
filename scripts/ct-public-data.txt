# Artifact-writing modules whose kernels run on PUBLIC data, so the leakage
# trace carries no secret and the constant-time obligation does not apply. One
# `path  # reason` per line, read by scripts/emit-ct-obligation-ratchet.sh.
#
# This is the module-level counterpart of the `publicData` flag that
# VIR/FieldEcCmpOps.lean puts on a comparison op: it does not change what is
# emitted, it records that the inputs are public. It is a claim about the
# kernel's use, not something the compiler checks, so each line states why.
#
# A kernel that takes a secret key, scalar, nonce or message does NOT belong
# here; it discharges the obligation instead (allDirect / lcmdDirect / a
# _constant_time theorem).

CatCrypt/Crypto/Jasmin/Examples/CombTableInit.lean  # builds the fixed comb table from the Ed25519 base point and the identity, both curve constants; the secret-dependent step is the table lookup, which is CombSelectKernel's obligation
CatCrypt/Crypto/Jasmin/Examples/CombTableInitArr.lean  # the array-slot form of the same table build, over the same two constant inputs
CatCrypt/Crypto/Jasmin/Examples/CombTableInitArrV2.lean  # the runtime-indexed form of the same table build, over the same two constant inputs
CatCrypt/Quantum/Benchmark/QrunchCompile.lean  # the quantum circuit compiler catq-compile writes the optimized OpenQASM 2 file of its input circuit; it emits no cryptographic kernel and handles no secret
CatCrypt/Quantum/Benchmark/QrunchExportMain.lean  # catq-export writes fixed quantum algorithm circuits (QFT, phase estimation, amplitude amplification) as OpenQASM 2 files; it emits no cryptographic kernel and handles no secret
CatCrypt/Crypto/Jasmin/Examples/XEdDSAVerify.lean  # signature verification: the public key, the signature and the message digest are the verifier's public inputs
CatCrypt/Hax/ReifyImpEmit.lean  # writes the Rust source text of reified Lean functions and their leaf stubs for the hax round trip; it runs no kernel, so there is no leakage trace
