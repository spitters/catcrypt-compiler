# Tier map of the machine-boundary ratchet (read by scripts/machine-boundary-ratchet.py).
#
# A rule is `<tier> <kind> <pattern>`. The first rule that matches a module gives its
# tier. Kinds:
#   family  a family label of the code map (SSProve-lean scripts/code-map/annotations.txt,
#           the generator behind NAVIGATION.md); a module belongs to the family whose row
#           is the first in that file with a glob matching the module's path
#   glob    <repo>:<path glob>; `**` crosses directories, `*` and `?` stay within one
#           path component
#   name    a module-name prefix, matched at a dot boundary; the only kind that applies to
#           an import resolving to no scanned module (a package outside the workspace)
# Repos: C catcrypt-compiler, K CatCrypt-core, D SSProve-lean, P ParamTransfer,
# H hax-lean, N nominal-lean.
#
# `machine:` names the tiers that form the machine library and `allowed:` the tiers its
# modules may import. A scanned module that no rule matches has tier `other`; an import
# that resolves to no scanned module and matches no `name` rule has tier `unresolved`.

machine: machine-core machine-back
allowed: toolchain
